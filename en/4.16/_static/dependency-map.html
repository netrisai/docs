Netris Object Dependency Map

Every object in Netris sits on a layer, and depends only on the layers above it. Click any object to see what must already exist before you can create it, and what it enables once it does. Read downward for build order, upward for teardown order.

Nothing selected Click an object in the map. Its prerequisites light up in blue, what it enables in green, and conditional dependencies are drawn as dotted lines.

Two ways to read it

Downward is build order. An object cannot exist until everything on the layers above it does, so the blue chain above a selection is the list of things to create first.

Upward is teardown order. Nothing can be removed while something below still depends on it. Most “it will not delete” problems are a layer being removed with something still standing on it.

A dotted edge is conditional — required only for some configurations, and the label says which.
